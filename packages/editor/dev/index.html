@aretino-chant/editor

CodeMirror-based web component for editing and previewing Aretino chant notation.

Live demo

Edit the Aretino source on the left. The rendered chant updates on the right in real time. A change event is fired on every document change.

Getting started

Install

npm install @aretino-chant/editor @aretino-chant/core

Register the custom element

import '@aretino-chant/editor'; // side-effect: registers <aretino-editor>

// Or, if you need the class directly:
import { AretinoEditor } from '@aretino-chant/editor';

HTML

<aretino-editor value="(g2) gh hg | ghg | g h i h ||" zoom="1.4"></aretino-editor>

JavaScript

const ed = document.querySelector('aretino-editor');

// Read and write the source text
console.log(ed.value);
ed.value = '(g2) g h i ||';

// Adjust the preview zoom
ed.zoom = 1.4;

// React to edits
ed.addEventListener('change', e => {
    console.log(e.detail.value);
});

API reference

Attributes & properties

Every attribute has a matching JS property of the same name.

NameTypeDefaultDescription
value string "" The Aretino source text shown in the editor.
zoom number 1 Preview magnification factor passed to renderAretino(). The physical staff spacing is small (≈ 1.5 mm), so a zoom of 1.2–1.5 is comfortable for editing.

Events

EventBubbles / composedDetailDescription
change yes / yes { value: string } Fired on every document change (every keystroke).

CSS customisation

The component uses Shadow DOM. The host element controls the overall size. The two panes are exposed via ::part():

PartDescription
editorThe CodeMirror editor pane (left).
previewThe live SVG preview pane (right).
 
aretino-editor {
    height: 320px;
    border: 1px solid #ccc;
    border-radius: 6px;
    overflow: hidden;
}

/* Make the preview pane take up 60% of the width */
aretino-editor::part(editor)  { flex: 2; }
aretino-editor::part(preview) { flex: 3; }

The component inherits no external styles into its Shadow DOM. CodeMirror's own theme API can be used to style the editor pane by passing a theme extension via the JS API (not yet exposed as an attribute — wire it in your integration layer).
